# 2. 修复 `should_skip_scan()` 中的顶点距离错误

当前代码大致使用：

```python
min(np.linalg.norm(v - P) for v in poly) > 1500
```

判断整个定位区域与检测点距离是否超过 1500 m。

这个判断不严格。

可能出现：

- 所有多边形顶点距 P 都 >1500 m；
- 但某条边的中部距 P <1500 m。

因此应改成：

> 求点 P 到整个凸多边形的真实最短距离。

实现/复用：

```python
point_to_segment_distance()
minimum_distance_to_polygon()
```

逻辑为：

1. P 在多边形内部 → 距离为 0；
2. 否则计算 P 到每条边线段的距离；
3. 取最小值。

建议把这些通用计算几何函数放进 `geo_common.py`，而不是让 Q3 import Q2。

最终结构应尽量类似：

geo_common.py

# 3. 修复 `process_channel()` 失败后频道永久丢失的问题

当前结构存在：

```python
t = remaining.pop(order[0])

if process_channel(...):
    cleared.add(ch)
```

的问题。

如果：

```python
process_channel(...) == False
```

则：

- 频道已经从 `remaining` 删除；
- 又没有进入 `cleared`；
- 后续不会重新处理；
- 最终只打印“未清除频道”并退出。

这不符合问题三“保证全部清除”的优先目标。

请改为明确的频道状态机，例如：

```text
discovered
→ processing
→ cleared

处理失败：
processing
→ retry_pending
→ 重新规划后再次处理
```

失败频道必须重新进入待处理集合。

但是不能无限循环。

建议维护：

```python
retry_count
last_failure_reason
observations
```

不同失败原因采取不同 fallback，而不是简单固定重试 N 次。

例如：

```text
第一次失败
→ 保留全部新观测
→ 重新计算 Ω
→ active localization 再处理

再次失败
→ 使用更保守策略

仍失败
→ homing/bracket emergency fallback
```

在最终退出前：

```python
set(discovered_channels) == cleared
```

应该成为一个显式检查。

只要还有已发现但未清除频道，就不应该正常宣布任务成功。

# 数学问题 A：单目标清除阶段的最优主动定位

这是本轮最重要的研究问题。

## A1. 已知状态

当前机器狗位置：

\[
P
\]

当前干扰源可能区域：

\[
\Omega
\]

其中 Ω 是 Q1 多次方位扇区交会得到的凸区域。

已经拥有全部历史观测。

---

## A2. 最终真正目标

不是把：

\[
D
\]

无限缩小。

而是尽快使：

\[
\rho(\Omega)
=
\min_C\max_{G\in\Omega}\|C-G\|
\]

满足：

\[
\rho(\Omega)\le20
\]

一旦满足即可去最小包围圆圆心清除。

因此：

> `D` 仍然可以作为定位质量指标，但清除阶段的最终停止条件应该以最小覆盖半径 `ρ` 为核心。

---

## A3. 下一检测点的稳健候选区域

下一检测点 S 不要求位于半径 1800 m 目标圆内。

为了保证未知接收半径最坏仅为 1000 m 时仍能收到信号，应要求：

\[
\max_{G\in\Omega}\|S-G\|\le1000
\]

即 Q2 中 robust candidate region 的思想。

请首先建立连续数学表示，再进行离散数值求解。

---

## A4. 不要直接拍一个 λ 做加权和

不要一开始直接使用：

\[
J(S)
=
\frac{\|S-P\|}{5}
+
5
+
\lambda D_{\rm after}(S)
\]

因为：

- 时间单位是秒；
- D 单位是米；
- λ 的取值会人为影响结果。

首先建立 Pareto 问题。

对于一个候选 S，定义：

```text
移动成本：
M(S) = ||S-P||

最坏后验定位质量：
Q(S)
```

其中 Q 可以优先研究：

\[
Q(S)=
\max_{\text{所有可能真实源和±1°误差}}
\rho(\Omega_{\rm after})
\]

同时可以记录：

\[
D_{\rm after}
\]

用于与 Q2 原指标对比。

---

## A5. 求移动距离与定位收益的 Pareto 前沿

例如研究：

```text
最大允许移动  50m
100m
150m
200m
300m
400m
...
```

在每个移动预算下求：

\[
\min Q(S)
\]

得到：

```text
移动距离
↔
下一次测量的最坏定位收益
```

的 Pareto 曲线。

然后再由模拟实验决定：

> 为减少总虚拟时间，实际策略应该选择 Pareto 曲线上的哪个区域。

---

## A6. 必须允许侧向、圆外观测

不要限制候选点：

\[
\|S\|\le1800
\]

如果某个目标位于目标圆边缘，并且现有观测方向近似共线，那么允许机器狗从圆外侧观测可能产生更大的交会角。

因此候选点只受：

```text
保证能收到信号
+
接口允许坐标范围
+
移动时间是否划算
```

约束。

---

## A7. 与现有 Q2 的关系

优先复用 Q2：

- robust candidate region；
- crossing angle；
- worst-case localization diameter；

但需要把 Q2 从“一次第二检测点选择”扩展为：

> Q3 清除阶段每获得一个新观测，就重新求下一最佳检测点。

也就是 receding-horizon / active localization。

不要复制一套几乎相同的代码。

应尽量抽出共享数学组件。

# 实验 11：Monte Carlo 批量随机测试

建立离线随机环境。

每轮：

```text
源数量 N ∈ [10,16]
频道互异
位置在半径1800圆盘内均匀采样
Ri ∈ [1000,1500]
```

圆盘内均匀采样注意使用：

\[
r=1800\sqrt U
\]

而不是：

\[
r=1800U
\]

避免中心密度偏高。

示向误差：

\[
[-1^\circ,1^\circ]
\]

需要尊重题目：

> 同一个检测位置重复测量时误差固定。

因此离线模拟器不能每次同地点 measure 都重新随机误差。

可以对：

```text
(source, position)
```

建立确定性的环境误差映射。

建议至少比较：

```text
Baseline：
Q3_fast2

Version A：
七边形 + bug fixes

Version B：
七边形 + bug fixes + MEC

Version C：
完整 active localization
```

统计：

- 清除比例；
- 是否出现任何未清频道；
- 总虚拟时间；
- 平均每源清除时间；
- P50 / P90 / P95 / maximum；
- 总移动距离；
- measure 次数；
- clear 次数；
- retry 次数；
- homing/bracket fallback 使用次数；
- 圆外 measure 次数；
- 圆外 measure 是否实际节省时间。

# Phase 4：最终将 Q3 主流程整理成新的统一逻辑

Phase 2 的数学问题解决后，再将主流程逐渐改成：

```text
发现频道
   ↓
维护该频道所有 observations
   ↓
计算当前定位区域 Ω
   ↓
求 Ω 的最小包围圆 (C*, ρ)
   ↓
┌─────────────────────────┐
│ ρ <= 20                 │
│                         │
│ → 移动到 C*             │
│ → clear                 │
│ → 成功则 cleared        │
└─────────────────────────┘

ρ > 20
   ↓
计算 robust candidate region：

max_G∈Ω ||S-G|| <= 1000

   ↓
候选点可以位于目标圆外
   ↓
根据 Phase 2 得到的 trade-off 策略
选择下一检测点
   ↓
移动 + measure
   ↓
获得 direction
   ↓
加入 observation history
   ↓
重新计算 Ω
   ↓
循环
```

只有当 active localization：

- 无有效候选；
- 异常；
- 或时间预算不足；

时才调用：

```text
homing_clear()
+
bracket_clear()
```

作为 fallback。
