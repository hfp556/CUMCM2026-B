# 2026 广东赛区 B题 提交前自查清单

> 本清单依据《论文格式规范（2026年修订稿）》和《广东赛区报名和参赛须知》整理。
> 以下任何一条违反都可能导致**取消评奖资格**，提交前逐条打勾确认。

## 一、论文格式（电子版）

- [ ] 论文为**单个 PDF 文件**（广东赛区只收 PDF，Word 会无法进入评阅系统，自动失去评奖资格）
- [ ] **第一页是摘要页**（含论文标题、摘要、关键词），**没有**承诺书和编号专用页
- [ ] 摘要（含标题和关键词）**不超过一页**，无需翻译成英文
- [ ] 页码：从摘要页开始编号，**页脚中部，阿拉伯数字从 1 连续编号**
- [ ] 正文**没有目录**，**不超过 30 页**
- [ ] 附录在正文之后、**同一个 PDF 文件内**
- [ ] A4 页面，四边距 ≥ 2.5 cm（模板已设好，勿改）
- [ ] PDF 大小 **≤ 20MB**，**不要压缩**
- [ ] 论文内任何地方（正文、附录、页眉页脚、批注、修订记录、**文档属性**）无学校、姓名、队号等身份信息
- [ ] 所有引用他人/网上资料已列参考文献，并在正文引用处标注 [序号]

## 二、附录（在论文 PDF 内）

- [ ] 含**支撑材料文件列表**
- [ ] 含建模所用**全部完整可运行源程序**（含 EXCEL/SPSS 交互命令）
  - 缺少源程序、程序不能运行、或运行结果与论文不符 → 取消评奖资格
  - 若确实没用程序：明确写"本论文没有用到程序"并说明原因
- [ ] 源程序**同时**放入支撑材料压缩包（广东特别要求）

## 三、支撑材料（压缩包）

- [ ] 用 WinRAR 压缩成**一个文件**（RAR 或 ZIP），≤ 20MB
- [ ] 包含：全部可运行源程序、自主查阅的数据资料（赛题原始数据除外）、较大篇幅中间结果图表
- [ ] 包含 **B题三次正式测试的日志文件**（从模拟器导出，**不要修改文件名**）
- [ ] 若使用了 AI 工具：包含"AI工具使用详情"PDF（文件名以此命名）
- [ ] 支撑材料与论文内容一致（不符 → 取消评奖资格）
- [ ] 压缩包内**任何位置**（文件夹名、文件名、文档属性）无队伍信息

## 四、AI 工具声明（论文参考文献之后）

- [ ] 未使用 AI：保留声明 **"本参赛队未使用任何AI工具"**
- [ ] 使用了 AI：正文相应位置标注 + 参考文献列出 AI 工具 + 支撑材料附使用详情
- [ ] 两种情况二选一，必写其一

## 五、B题内容专项

- [ ] 问题3、问题4 各做**三次正式测试**，论文中按**表1格式**填结果（测试案例编码、清除干扰源个数、平均定位清除时间、程序运行时间）
- [ ] 两个统计指标公式与数值齐备：清除比例 = 清除数/总数；平均定位清除时间 = 总时间/清除数
- [ ] 演练测试过程与结果有说明
- [ ] 三次正式测试日志已导出、未改名、已放入支撑材料

## 六、提交流程（广东赛区）

- [ ] **9月13日 20:00 前**：通过2026客户端生成并提交论文和支撑材料的 **MD5 码**
  - 上传 MD5 **之前先关闭文件**（打开保存过 MD5 就变了，须重新生成提交）
  - 多次上传以最后一次为准；**提前 1 小时**完成，必要时用手机热点
  - 上传成功后备份文件，备份**不要再打开**
- [ ] **9月13日 20:30 – 9月14日 14:00**：用客户端上传与已提交 MD5 对应的论文和支撑材料
- [ ] 模拟器测试：**9月13日 15:30 前**完成全部正式测试（17:30 后不能再启动新测试）
- [ ] 只有报名信息中**第一位学生**能登录客户端；客户端必须用 2026 版，Windows 系统，分辨率调到最高
- [ ] 承诺书已按要求交给学校（由学校统一收集）

## 七、纪律红线

- [ ] 竞赛期间未与队外任何人（含指导教师）交流赛题
- [ ] 未在贴吧、QQ群、微信群、知乎、小红书、CSDN、GitHub 等平台浏览、发布、讨论赛题
